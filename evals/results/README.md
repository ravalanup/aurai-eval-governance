# Evidence

Evidence files written by `aurai-governance evals import` and `import-retrieval`, one per use case and suite
(`<use-case>/<suite>.json`, platform suites under `_platform/`). Only live runs belong here. The promotion gate
reads these files; see [docs/promotion-gates.md](../../docs/promotion-gates.md).

No evidence is committed yet: it needs a gateway and a model. See [docs/evals.md](../../docs/evals.md) for how to produce it.
